# wt-nettest — проверка соединения без настройки роутера

Проверяет, смогут ли два компьютера в разных сетях соединиться через
[iroh](https://docs.rs/iroh) (QUIC + пробивка NAT + relay) без проброса портов.
Видео не передаётся, только пинги раз в секунду в течение 60 секунд.

## Скачать

Release **nettest**: `wt-nettest-macos.zip` (Apple Silicon и Intel) и
`wt-nettest-windows.exe`.

## Как проверить

1. **Ведущий** запускает программу, выбирает `1`. Ждёт строку `WT1-…` и
   отправляет её другу целиком. Окно не закрывает.
2. **Зритель** запускает программу, выбирает `2`, вставляет код, нажимает Enter.
3. Через 60 секунд у зрителя появится итог: напрямую, через relay или не работает.
4. Оба присылают файл лога `wt-nettest-<число>.txt` из домашней папки.

### macOS: если система не даёт открыть

Программа не подписана сертификатом Apple. В Терминале:

```bash
xattr -d com.apple.quarantine ~/Downloads/wt-nettest
chmod +x ~/Downloads/wt-nettest
~/Downloads/wt-nettest
```

Либо: Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».

### Windows: SmartScreen

«Подробнее» → «Выполнить в любом случае». Если Windows спросит про доступ
к сети, разрешить.

## Из исходников

```bash
cd tools/nettest
cargo run --release            # меню
cargo run --release -- host
cargo run --release -- join WT1-...
```
