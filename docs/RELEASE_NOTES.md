# Подключение без настройки роутера

- Совместный просмотр использует отдельный локальный файл у каждого участника.
- Соединение идёт через iroh (QUIC, пробивка NAT, relay): проброс портов и VPN не нужны. Файл по сети не передаётся.
- Приглашение — один код `WT2-…` или ссылка: адрес ведущего вводить не нужно. Старые коды `WT1-…` не подходят.
- Подключение ждёт ответ ведущего; недоступный ведущий, неверный токен и другая длительность фильма показывают ошибку.
- Синхронизируются запуск, пауза, перемотка и скорость; время корректируется по измеренной задержке.
- Ссылки watchtogether:// зарегистрированы для открытия приложения.
- macOS: в сборку входят все библиотеки видеоплеера (раньше не хватало libbrotlicommon, и приложение падало при запуске без Homebrew). Нужна macOS 15 или новее.
- Видео до 1080p и 60 кадров/с на macOS и Windows. На Windows кадры идут через общую память WebView2 и WebGL вместо копирования через IPC (раньше — до 1280×720 и около 30 кадров/с); на macOS кадр выводится сразу по готовности, а не по таймеру.
- Озвучку отдельным файлом (`.mp3`, `.m4a`, `.ac3`, `.flac`, `.mka` и др.) можно добавить как аудиодорожку: меню аудио → **Add External Audio…** или перетаскиванием в окно.
- Windows: видео рисуется на видеокарте. Если для монитора включён HDR (Параметры → Дисплей → «Использовать HDR»), HDR-фильмы выводятся в HDR; на обычном мониторе они правильно сжимаются в обычный диапазон вместо блёклой картинки. Без подходящей видеокарты остаётся прежний вывод.
- macOS: HDR-фильмы выводятся в HDR (EDR) на экранах XDR и внешних HDR-мониторах; на обычных экранах — тон-маппинг в обычный диапазон. Яркость подстраивается под текущий запас яркости экрана.
- Мини-окно без рамки: только видео, тянется за края, перетаскивается мышью; при наведении — назад/пуск/пауза/вперёд и «развернуть», в том числе когда активно другое приложение.
- Компьютер и экран не засыпают, пока идёт видео.
- Приложение само сообщает о новой версии (плашка **Update available**) и ставит её одной кнопкой.
- Клавиша **I** показывает статистику воспроизведения: реальные кадры/с, потерянные кадры, разрешение и декодер.

Обоим участникам нужна эта версия приложения: с прошлыми версиями она не соединяется.

[Подробная инструкция](SELF_HOSTED_SYNC.md). Реальную пару Mac + Windows в разных сетях необходимо проверить отдельно от автоматических тестов.
