# Изменения

- Видео открывается внутри окна Watch Together вместо отдельного окна mpv.
- Хоткеи поддерживают русскую раскладку; полноэкранный режим управляет окном приложения.
- Обновляются списки аудиодорожек и субтитров; исправлена загрузка внешних SRT и работа встроенных ASS.
- Новая иконка: светлый градиент, металлическая кромка и чёрный Play.

## Установка на Mac

Скачайте **Watch_Together_macOS.dmg** в разделе Assets ниже, откройте его и перетащите приложение в Программы. Архивы Source code содержат только исходники.

Тестовая сборка для Apple Silicon. Подпись ad-hoc, нотариализации Apple нет. Работа изображения, фокуса и полноэкранного режима требует проверки на реальном Mac.

## Установка на Windows x64

В разделе Assets скачайте **WatchTogether-Windows-x64-Setup.exe** и запустите установку. ZIP **WatchTogether-Windows-x64.zip** содержит тот же EXE в корне архива. Windows-файлы добавляются в релиз после успешного завершения Windows CI, включая тесты, сборку и проверку установки с загрузкой комплектной libmpv.

## Исправления сборки Windows

Проверки ограничителя частоты событий используют точные монотонные метки времени вместо микросекундных пауз, длительность которых зависит от ОС. Порог 250 мс сохраняется.
